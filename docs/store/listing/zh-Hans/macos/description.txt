Snapfly 把你拍下的每张截图挂在屏幕顶部的晾衣绳上，并在任何内容离开 Mac 之前遮盖隐私信息。

晾衣绳
把指针停在菜单栏，晾衣绳就带着你的截图降下来；移开指针，它又收起来。截图不再堆满桌面。Snapfly 会告诉你一次，应把“截屏”App 的存储位置指向哪里。

直接发到聊天
点按照片上的纸飞机，或按 ⌃⌥V，照片就直接进入你正在输入的 App。每张照片下方的图标可将它发送到 ChatGPT、Claude、WhatsApp 或 Gmail。发送后，照片会离开晾衣绳。

隐私信息，先遮盖
无论拷贝、发送还是拖出，离开晾衣绳的内容都会遮盖你在“隐私”中选择的信息：姓名、地址、出生日期、电子邮件、电话号码、人脸、银行卡和账户、金额、健康信息、证件号和税号、订单号和快递单号、二维码和条形码、密码、API 密钥以及 IP 地址。你的姓名、地址和自定规则放在“始终隐藏”中。其他内容可以用“遮盖部分”手动遮盖。还可以选择遮盖的样式，或保留后四位。

晾衣绳上的更多功能
- “拷贝文本”拷贝截图中的文字。
- 把多张截图合并为一张图片，或做成一个 PDF。
- “翻译文本”和“生成描述”，在 Mac 上使用 Apple 自己的功能完成。
- 用 ⌃⌥F 搜索所有截图中的文字。
- 用 ⌃⌥R 录制屏幕，并在 Studio 中添加缩放和箭头。
- 也可以挂上 Finder 中的照片和 PDF，它们同样会遮盖后再离开。
- “遮盖文件”一次遮盖大量 PDF 和图片，生成遮盖后的副本。

Mac 与 iPhone
打开同步后，Snapfly 的 iPhone 版会通过你自己的 iCloud 保持一致。只发送遮盖后的副本，除非你也选择了原件。

在你的 Mac 上
识别、遮盖和翻译都在你的 Mac 上完成。无需账户。没有跟踪。
